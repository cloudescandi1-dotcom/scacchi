# Informativa sulla privacy — Scacchi

Ultimo aggiornamento: 28 ottobre 2026. Titolare: cloudescandi1-dotcom.

- **Niente account, email, cookie, pubblicità o statistiche.**
- La partita in corso e i progressi delle lezioni sono salvati **solo sul tuo dispositivo**
  (memoria del browser). Il gioco non invia dati a nessun server: anche il computer
  avversario gira tutto sul tuo dispositivo.
- Il sito è ospitato da GitHub Pages, che può registrare dati tecnici delle visite
  (per esempio l'indirizzo IP) secondo la propria informativa:
  https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement
- Per cancellare i dati: cancella i dati del sito dal browser o disinstalla l'app.
